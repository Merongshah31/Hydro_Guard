# Hydro_Guard
![hydroguard](https://github.com/user-attachments/assets/332d7e14-2a06-4277-8911-25e0bd05320a)


HydroGuard is a smart flood prediction system powered by machine learning, designed to forecast potential flood events using real-time environmental and weather data. By leveraging TensorFlow and deep learning techniques, HydroGuard aims to provide early warnings and support disaster risk management in flood-prone areas.
